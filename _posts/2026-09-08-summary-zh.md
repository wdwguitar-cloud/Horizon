### [最高法发布 AI 纠纷司法解释，明确换脸与算法杀熟责任](https://www.cnr.cn/news/20260907/t20260907_527806795.shtml) ⭐️ 8.0/10

最高人民法院 9 月 7 日发布人工智能纠纷案件司法解释，全文共 5 部分 24 条，聚焦 AI 换脸、算法杀熟、冒充他人代言、自动驾驶和知识产权等问题。解释明确，未经同意利用 AI 制作可识别他人人脸、声音等内容的，可能构成人格权侵权；算法价格歧视侵害消费者权益的，相关主体应承担责任。对使用 AI 冒充他人代言并诱导消费的行为，解释支持权利人依法提出的惩罚性赔偿请求。解释同时把利用 AI 实施“网络开盒”“人肉搜索”等侵害自然人隐私权的行为纳入规制范围。

telegram · zaihuapd · 9月7日 09:32

**「背景」** 生成式 AI 技术会放大信息误导和身份冒用风险，但以往民事法律对深度伪造、差异化定价等新型侵权的责任认定缺少统一细节。此次最高法以司法解释形式统一裁判规则，为法院审理相关人格权、消费者权益案件提供更具体的法律依据。

**「影响」** 对中国境内提供 AI 换脸、深度合成、算法推荐等服务的企业而言，新的司法解释意味着合规与应诉标准更加明确，未经同意的生成内容及算法歧视行为可能直接带来民事赔偿乃至惩罚性赔偿。被侵权的个人则可以依据该解释，更直接地就人脸、声音被滥用、遭遇算法杀熟或遭冒充代言等情况主张权利。

**标签**: `#AI regulation`, `#deepfakes`, `#algorithmic pricing`, `#China`, `#legal tech`

### [滥用爬虫让 git.kernel.org 白费大量 CPU](https://simonwillison.net/2026/Sep/7/creepy-crawlies/) ⭐️ 7.0/10

Linux 内核官方 Git 托管服务 git.kernel.org 的维护者 Konstantin Ryabitsev 报告称，滥用爬虫造成的“背景辐射”已严重到为爬虫渲染提交页面所消耗的 CPU 周期，超过了包括 git clone 在内的所有合法访问的总和。目前该服务分布在 5 个地理分布式节点上，任意时刻都有 14 个 CPU 核心仅用于将 git 提交渲染成 HTML。Simon Willison 在转发时表示，这让他从 Datasette 这类提供大量可抓取网页的服务角度感到担忧。

rss · Simon Willison · 9月7日 23:08

**「背景」** git.kernel.org 是 Linux 内核的官方 Git 仓库托管站点，其网页界面需要把提交、分支、文件等 Git 对象动态渲染成 HTML 供浏览器查看。搜索引擎、AI 训练数据采集器等爬虫会批量抓取这些页面，每次请求都会触发一次完整渲染，CPU 开销远高于普通用户通过 Git 协议进行克隆或拉取的流量。这篇文章基于 kernel.org 的实际运维观察，指出了这种“爬虫背景辐射”正在成为公共 Web 服务不可忽视的资源负担。

**「影响」** 这一案例提醒所有运行公开可抓取动态网页的团队，滥用爬虫可能消耗不成比例的 CPU 资源，运营者应监控不同用户代理或来源的请求占比，并对异常高频抓取加以限制或缓存处理。

### [从登山救援到 GPT-6 Astra：AI 能力越强信任风险越大](https://www.reddit.com/r/artificial/comments/1wa5i9p/three_hikers_got_rescued_off_a_mountain_this_week/) ⭐️ 7.0/10

9 月 1 日，三名来自 Roseville 的徒步者使用 Gemini 规划 Mount Shasta 登顶，AI 建议携带远少于实际所需的食物和水；他们在建议的最后折返时间四小时后于晚上 7 点登顶，天黑下撤途中一人膝盖受伤，困在峡谷过夜，直到次日上午被护林员救出。Google 表示无法复现 Gemini 当时给出的错误答案。两天后，OpenAI 发布 GPT-6 Astra，在 ARC-AGI-3、FrontierMath Tier 4 和 ExploitBench 上分别取得 99.9%、97.6%和 100%的成绩，并称这是 AGI 时代的开始；Artificial Analysis 的独立基准则显示 Anthropic Fable 5.1 在更广泛的智能指数上仍领先。作者指出，模型能力提升会让更多人信任其用于高风险场景，但用户对其局限的理解不会自动跟上，输出越有说服力，越难判断何时不该信任。

reddit · r/artificial · /u/Dapper-Tale-4021 · 9月7日 21:47

**「背景」** 生成式 AI 输出流利而肯定，但并非天然可靠的知识来源；在登山、医疗等高影响场景中，用户容易把模型当作专家。此次登山事故与 GPT-6 Astra 宣称的更强能力形成对照，凸显了技术能力与用户对模型边界理解之间的错位。

**「影响」** 对把 AI 用于规划与安全相关任务的用户和组织而言，这一事件的具体警示是：在无法由专业人士复核的语境中，不能把模型输出当作权威建议，即使新模型能力更强，也应以明确的人工验证步骤和预设的安全边界来约束信任。

**标签**: `#AI safety`, `#Gemini`, `#GPT-6 Astra`, `#AGI`, `#AI reliability`
